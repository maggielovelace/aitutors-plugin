# Heddy for Chrome

[English](README.md) · **简体中文**

**收下你找到的东西。** 配合 [aitutors.me](https://aitutors.me) 使用。

Heddy 在每个 YouTube 视频页的「分享」按钮后面加一个按钮：**和 Heddy 一起看**。
它会在 YouTube 的推荐栏里打开**教授的书桌**（剧场模式或窄窗口时在播放器下面）：
和课堂里的书桌一样，有**随记**（按 **H** 记下正在说的这句，快速按两次连上前一句，
也可以自己写一条）、**精读**（文字稿，英文、双语或中文，跟着播放器走，点一句就跳过去）、
aitutors.me 有内容时的**见解**，还有可以问教授的徽章。**存到我的 Jotters** 把随记存进
这个视频的笔记本；**完整书桌** 把视频放进「我的短片」，带着随记在课堂里打开。
书桌说英文或中文（它的 EN | 中 就是 Heddy 的语言设置），📌 让每个视频都打开书桌。

**放进「我的短片」** 在 YouTube 视频上的 Heddy 面板里：视频的缩略图和准确链接、
一条视频画面胶片，拖动金色框的两头选一段，还有「整个 · 最后 30 秒 · 从现在起」。
点工具栏上的 Heddy 图标，面板会出现在
页面右上角。滚动页面、选文字或点页面时它都留着，点它的 ✕、按 Esc 或再点一次
图标才会关上。在 Chrome 不让扩展程序进入的页面上（`chrome://` 页面、网上
应用店），它会改为一个小窗口。

Heddy 只是个「快递员」。它不保存账号、密钥或令牌：每次点按钮，都会打开
aitutors.me 上的一个页面，由那个页面检查视频，并在孩子自己的账号下保存，
孩子在那里点一下就好。它自己的请求只发给 aitutors.me，并由浏览器带上你在
aitutors.me 的登录：问现在是谁登录（设置页的学习通行证和面板里的账号行），以及书桌的
教授、文字稿、见解和「存到我的 Jotters」（`lib/desk-api.js`）。「完整书桌」和「放进
「我的短片」」会在视频旁边新开一个标签页，收下之后 Heddy 会把它关掉，带你
回到视频；其他操作打开一个小窗口。

在任意网页上还可以：

- **在 YouTube 视频上按 H**（书桌开着时），把正在说的那句话记进书桌的随记。快速按两次，
  会连上前一句。书桌关着时 H 什么也不做；YouTube 自己的按键（包括 J）一直照常使用。
- **先收集，再「存到 Jotters」**：点 Heddy 的图标，它的面板会一直留在页面上。
  面板开着的时候，**选中的每段文字都会自动加成下一张卡片**（5 秒内拉长或缩短，
  卡片会跟着改；不想要的点 ✕ 去掉）。「+ 文字」和「+ 图片」是一个开关：点「+ 图片」
  再框一张图。每一样都是一张带编号的卡片，页面上的高亮和图框旁边也标着同样的编号。
  按住 ⠿ 拖动卡片，或点 ↑ / ↓（选中卡片后按 Alt+↑ / Alt+↓），按你的顺序排好。
  同一个网页最多 10 段文字、4 张图片；换到别的网页就会清空。点「存到 Jotters」，
  它们会按你排的顺序放进这一页的 Jotter 左页，你在那里写批注；点「存下，马上写批注」
  会直接打开批注本。「讲解」「做成卡片」「问 Heddy」针对第 1 张卡片。
- **截一张图**（面板里的「+ 图片」，或按 Ctrl Shift K，面板也会一起打开）：图框下面是
  「文字 | 图片」开关 ·「+ 图片」（收下这张）·「Heddy ▾」，菜单里有「讲解这张图」
  「做成卡片」「问 Heddy 这张图」「复制图片」和「整个可见页面」。保存在面板里。
  按 Esc 或点开关上的「文字」，就回到选文字。
- **右键**选中的文字 →「存到 Jotters」，或右键图片 →「把图片加到 Heddy」：都会成为
  下一张卡片，面板随之打开。选中文字下方的 Heddy 按钮（「+ 加入」「讲解」「做成卡片」
  「问 Heddy」）可以用你自己在 `chrome://extensions/shortcuts` 设的快捷键调出（Heddy
  默认不设，所以不会占用 Chrome 自己的快捷键）。连按两次 Ctrl Shift K，会把整个可见
  页面收成一张卡片。Heddy 不会替你写批注：批注在批注本里、对着左页来写。
- **存到 Jotters**：把网页的正文存进 Jotters，作为来源。很长的网页只保留前一部分，
  Heddy 会告诉你。

## 安装

**从 Chrome 网上应用店安装：** 上架后会在这里放链接。

**从源码安装**（测试用，或在上架之前）：

1. 下载这个仓库（Code → Download ZIP）并解压，或者
   `git clone https://github.com/maggielovelace/aitutors-plugin`。
2. 打开 `chrome://extensions`，打开右上角的 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择 `heddy-chrome` 文件夹。
4. 在拼图图标菜单里固定 Heddy，然后打开任意一个 YouTube 视频。

请在同一个 Chrome 里以孩子的身份登录 aitutors.me。如果还没登录，aitutors.me
的标签页或小窗口会先请你登录，然后接着完成。

## 设置

右键点 Heddy 图标 → **选项**，或点 Heddy 面板里的齿轮：

- **语言**：English 或 简体中文。默认跟随 Chrome 的语言。aitutors.me 上的
  窗口跟随你在网站上选的语言。
- **开发者选项**：把内容发到 `http://localhost:3000`，而不是 aitutors.me。
  请保持关闭。

## 给学校

学校管理的 Chromebook 可能会禁止安装扩展程序。要允许 Heddy，请在 Google
管理控制台的允许列表里加入它的 ID：

```
扩展程序 ID：（上架 Chrome 网上应用店后填写）
```

aitutors.me 上没有任何功能依赖 Heddy：没有它，孩子照样可以在「快速添加」
页面添加视频。

## 隐私

**只有你让它读，它才会读页面。** Heddy 只在 YouTube 视频页
（`https://www.youtube.com/watch…`）上读取视频 ID；书桌开着时，读视频的标题、频道、
播放器的时间和时长，书桌开着时会收起 YouTube 的推荐，关上时放回来；文字稿不从页面读，
由 aitutors.me 发来（`/api/learn/heddy/desk/…`，同样带上你的登录 Cookie）。
打开面板时，读视频的标题、频道、时长、当前时间和 YouTube 自己的预览画面给你看；
缩略图和画面来自 YouTube 自己的 `i.ytimg.com`。随记在你保存之前只存在这台电脑上。在其他网页上，只有你打开面板、
右键「存到 Jotters」或按你设的快捷键时，它才读你选中的文字和前后各最多
300 个字符；点「存到 Jotters」时，才读这一页的正文。它不从页面读字幕，也不读评论、浏览记录或 Cookie，不做统计，也不上报
错误。打开设置页，或在不能保存的页面上打开面板时，Heddy 会问 aitutors.me 一次
现在是谁登录（`GET /api/learn/heddy/me`，由浏览器带上你在 aitutors.me 的登录
Cookie，Heddy 自己不读也不存这个 Cookie）。回答最多是孩子的名字、年级和科目；
Heddy 只把它显示出来，不保存，也不发给任何别处。你点「截一张图」、右键图片或按 Ctrl Shift K 时，它才截下屏幕上能看到的部分，只保留你框出的那一块。
在 Chrome 网上应用店里，这些都申报为「网站内容」：只在你让它读时（存到 Jotters、加入卡片、截一张图、讲解、做成卡片、问 Heddy）才收集，只交给 aitutors.me、存在你自己的账号里；绝不出售，不用于广告或信用评估，除 aitutors.me 自己的处理外不与任何第三方分享。完整说明见 [PRIVACY.md](PRIVACY.md)（英文）。

## 测试

```bash
cd heddy-chrome
npm test
```

需要 Node 20 或更高版本，没有依赖。测试会锁定权限列表、禁止发布文件里出现
除「谁已登录」（`lib/who.js`）之外的任何网络请求、检查每个 `cid` 只回答一次并在 10 分钟后过期，并用网站的校验
规则检查每条消息。
