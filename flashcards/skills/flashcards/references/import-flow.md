# What happens after you hand over the JSON

This skill has no API access and holds no account state — it produces a
fenced JSON block and stops. Tell whoever you're helping to do this:

1. Go to **aitutors.me/study/cards/new/import** (they need an aitutors.me
   account with an active subject — this is a feature inside the product,
   not a public tool).
2. Paste the JSON block into the box and confirm the check.
3. They'll see a preview of every card before anything is saved — the
   subject and topic are confirmed there too, since your JSON may not have
   guessed either correctly.
4. Once they add them, the cards go straight into their own private practice
   pile. Nobody else — no other child, no moderator — ever sees them; that
   is deliberately the SAME privacy boundary as a card they typed by hand in
   the product's own composer.
5. They land as editable drafts and are safe to tweak from the product's own
   "tidy up" screen before the first time they're graded — after that, the
   platform freezes the wording (so review history stays honest).

If the import screen rejects one or more cards, it will say which ones and
why (in the same terms as `qa-checklist.md`) — the fix is to bring the
corrected JSON back to this conversation and ask for those specific cards to
be redone, then re-paste the whole set.

There is no bulk/CSV import, no editing an already-imported deck from this
skill, and no way to import into someone else's account — one JSON block, one
deck, one account, confirmed by the person doing the importing.
